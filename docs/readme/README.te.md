**HTML PGP** అనేది [Kleopatra](https://apps.kde.org/kleopatra/) — GnuPGతో వచ్చే సర్టిఫికెట్ మేనేజర్ — తరహాలో పనిచేసే OpenPGP కీ మేనేజర్, ఎన్‌క్రిప్షన్ సాధనం; అదీ ఒకే స్వతంత్ర HTML ఫైల్‌లో. ఇందులో మీ సొంత కీ జతలు, ఇతరుల పబ్లిక్ కీలు ఉండే కీరింగ్ ఉంటుంది. దీనితో కొత్త కీలు సృష్టించవచ్చు (RSA, Curve25519, NIST, Brainpool కర్వ్‌లు, OpenPGP v6 Ed25519, Ed448), కీలను సర్టిఫై చేయవచ్చు, టెక్స్ట్‌ను, ఫైళ్లను ఎన్‌క్రిప్ట్ చేయవచ్చు, సంతకం చేయవచ్చు, డిక్రిప్ట్ చేయవచ్చు, ధృవీకరించవచ్చు.

ఇది GnuPG, Kleopatra మాట్లాడే OpenPGPనే మాట్లాడుతుంది: కీలు, సందేశాలు, సంతకాలు రెండు వైపులా పనిచేస్తాయి, పరీక్షలు దీన్ని GnuPGతోనే సరిపోల్చి చూస్తాయి.

అంతా ఆఫ్‌లైన్‌లో పనిచేస్తుంది: ఖాతా లేదు, సర్వర్ లేదు, నెట్‌వర్క్ అభ్యర్థనలు లేవు — పేజీకి నెట్‌వర్క్ యాక్సెస్ అసలే లేదు. కీలు బ్రౌజర్‌లో ఉంటాయి; సీక్రెట్ కీలు వాటి పాస్‌ఫ్రేజ్‌లతో ఎన్‌క్రిప్ట్ అయి ఉంటాయి, పాస్‌ఫ్రేజ్‌లను ఎప్పుడూ నిల్వ చేయరు. ఇదే పేజీ [PWA](#github-pages)గా యాప్ లాగా ఇన్‌స్టాల్ అవుతుంది, [Chrome పొడిగింపు](#chrome-పొడిగింపు)గా మీ ట్యాబ్‌ల పక్కనే తెరుచుకుంటుంది.

## ఉపయోగించే విధానం

`build/html-pgp.html`ను నిర్మించి ("[బిల్డ్](#బిల్డ్)" చూడండి) బ్రౌజర్‌లో తెరవండి — నేరుగా డిస్క్ నుండి తెరిచినా సరిపోతుంది. లేదా GitHub Pagesలోని PWAను వాడండి, లేదా పొడిగింపును.

Kleopatraలో లాగానే యాప్‌లో మూడు వీక్షణలు ఉన్నాయి: **కీలు**, **నోట్‌ప్యాడ్**, **ఫైళ్లు**, అలాగే **సెట్టింగ్‌లు**.

### కీలు

- **కొత్త కీ జత** — మీ పేరు, ఇమెయిల్ చిరునామా, సీక్రెట్ కీని కాపాడే పాస్‌ఫ్రేజ్. "అల్గారిథమ్, చెల్లుబాటు" కింద: అల్గారిథమ్ ("[అల్గారిథమ్ ఎంపికలు](#అల్గారిథమ్-ఎంపికలు)" చూడండి), కీ ఎంతకాలం చెల్లుతుందో — GnuPG, Kleopatra సృష్టించినట్లే డిఫాల్ట్‌గా మూడేళ్లు. కీ సృష్టించిన వెంటనే దాన్ని బ్యాకప్ చేసుకోమని యాప్ సూచిస్తుంది: కీరింగ్ ఈ బ్రౌజర్‌లో మాత్రమే ఉంటుంది.
- **ఇంపోర్ట్** — ఫైల్ నుండి (`.asc`, `.gpg`, `.key`… ప్రతిదానిలో ఒకటి లేదా అనేక కీలు, ఆర్మర్డ్ లేదా బైనరీ), క్లిప్‌బోర్డ్ నుండి, లేదా టెక్స్ట్‌గా పేస్ట్ చేసి. కీల వీక్షణపై వదిలిన ఫైళ్లు కూడా ఇంపోర్ట్ అవుతాయి. కీరింగ్‌లో ఇప్పటికే ఉన్న కీ విలీనం అవుతుంది: కొత్త యూజర్ IDలు, సబ్‌కీలు, సంతకాలు అందులో చేరతాయి, సీక్రెట్ కీ దాని పబ్లిక్ కీతో కలుస్తుంది. GnuPG ఉపసంహరణ సర్టిఫికెట్ (`.rev`) మీరు నిర్ధారించిన తర్వాతే ఇంపోర్ట్ అవుతుంది: అది కీని శాశ్వతంగా ఉపసంహరిస్తుంది.
- **ఎక్స్‌పోర్ట్** — ఎంచుకున్న పబ్లిక్ కీలను, టెక్స్ట్‌గా (`.asc`) లేదా బైనరీగా (`.gpg`), ఫైల్‌కు లేదా క్లిప్‌బోర్డ్‌కు. ⌘/Ctrl, Shiftలతో అనేక కీలను ఎంచుకోవచ్చు.
- జాబితాలో ప్రతి కీ పేరు, చిరునామా, చెల్లుబాటు, గడువు తేదీ, కీ ID కనిపిస్తాయి; శోధన పేరు, చిరునామా, కీ ID లేదా ఫింగర్‌ప్రింట్‌తో కీలను కనుగొంటుంది, ఫిల్టర్ మీ కీ జతలను, సర్టిఫై చేసిన కీలను, ఎవరూ సర్టిఫై చేయని కీలను, లేదా గడువు ముగిసిన, ఉపసంహరించిన కీలను చూపిస్తుంది.

కీ వివరాలలో దాని ఫింగర్‌ప్రింట్ నాలుగేసి అక్షరాల సమూహాలుగా (GnuPG ముద్రించినట్లే), దాని యూజర్ IDలు, వాటిని ఎవరు సర్టిఫై చేశారు, ప్రాథమిక కీ, సబ్‌కీలు వాటి అల్గారిథమ్‌లు, వినియోగం, తేదీలతో, పబ్లిక్ కీ టెక్స్ట్‌గా కనిపిస్తాయి. మీ సొంత కీలకు ⋯ మెనూలో ఇవి కూడా ఉంటాయి:

- **గడువు మార్చండి** — కీకి, దాని సబ్‌కీలకు కొత్త తేదీ, లేదా గడువు లేకుండా. తర్వాత పబ్లిక్ కీని మళ్లీ షేర్ చేయండి, అప్పుడు ఇతరులకు అది కనిపిస్తుంది.
- **యూజర్ ID జోడించండి** — అదే కీకి మరో పేరు లేదా చిరునామా. ప్రాథమికమైనది ప్రాథమికంగానే ఉంటుంది.
- **పాస్‌ఫ్రేజ్ మార్చండి** — ప్రస్తుతది గుర్తుంచుకున్నప్పటికీ ముందుగా అదే అడుగుతుంది. ఖాళీ పాస్‌ఫ్రేజ్ పెడితే, హెచ్చరిక తర్వాత కీ రక్షణ లేకుండా ఉంటుంది.
- **సీక్రెట్ కీ బ్యాకప్** — సీక్రెట్ కీ, ఇంకా దాని పాస్‌ఫ్రేజ్ కింద ఉన్నట్లే, `Name_0xKEYID_SECRET.asc` పేరుతో. పాస్‌ఫ్రేజ్ ముందుగా అడుగుతుంది, కాబట్టి బ్యాకప్ తెరుచుకుంటుందని తెలుస్తుంది.
- **ఉపసంహరణ సర్టిఫికెట్** — కీతో పాటు సృష్టించినది, కీకి వేరుగా ఉంచుకోవాలి: కీ పోతే లేదా దొంగిలించబడితే, సర్టిఫికెట్‌ను ఇంపోర్ట్ చేసి ఉపసంహరించిన కీని షేర్ చేయండి.
- **కీని ఉపసంహరించండి**, అలాగే అనేక యూజర్ IDలలో ఒకదాన్ని **ఉపసంహరించండి**.

### సర్టిఫై చేయడం

కీని సర్టిఫై చేయడం అంటే "ఈ కీ ఈ వ్యక్తిదే అని నేను తనిఖీ చేశాను" అని చెప్పడం. ముందుగా ఫింగర్‌ప్రింట్‌ను దాని యజమానితో తనిఖీ చేయండి — ప్రత్యక్షంగా కలిసి, లేదా వారి గొంతు మీకు తెలిసిన కాల్‌లో — తర్వాత కీ వివరాలలో **సర్టిఫై చేయండి** నొక్కి, యూజర్ IDలను ఎంచుకోండి. సర్టిఫికేషన్ మీ కీ ప్రాథమిక కీతో, GnuPG చేసినట్లే చేయబడుతుంది, GnuPG దాన్ని అంగీకరిస్తుంది.

చెల్లుబాటు Kleopatra వెబ్ ఆఫ్ ట్రస్ట్ యొక్క అత్యంత సరళమైన అర్థాన్ని అనుసరిస్తుంది: మీ సొంత కీలను పూర్తిగా నమ్ముతారు; మీరు సర్టిఫై చేసిన కీ **సర్టిఫై చేయబడింది**; ఇతర ఏ కీ అయినా పనిచేస్తుంది, కానీ అది ఎక్కడ వాడినా — జాబితాలో, గ్రహీతలలో, అది చేసిన సంతకంపై — **సర్టిఫై చేయలేదు** అని గుర్తు ఉంటుంది.

### నోట్ ప్యాడ్

సందేశం టైప్ చేయండి, **గ్రహీతలను** ఎంచుకోండి — టైప్ చేస్తుండగా పేరు, చిరునామా లేదా కీ IDతో దొరుకుతారు — ఆపై **ఎన్‌క్రిప్ట్ చేయండి** నొక్కండి, లేదా "దీనిగా సంతకం చేయండి" కింద కీ ఎంచుకుని ఉంటే **సంతకం చేసి ఎన్‌క్రిప్ట్ చేయండి**. "నాకు కూడా ఎన్‌క్రిప్ట్ చేయండి" మీ సొంత కీని చేరుస్తుంది, తద్వారా మీరు పంపినది మీరూ చదవగలరు. "పాస్‌వర్డ్‌తో ఎన్‌క్రిప్ట్ చేయండి" ఎవరైనా డిక్రిప్ట్ చేయగల పాస్‌వర్డ్‌ను చేరుస్తుంది, గ్రహీతలతో పాటు లేదా వారికి బదులుగా. **సంతకం మాత్రమే** క్లియర్-సైన్డ్ టెక్స్ట్ తయారుచేస్తుంది: ఇంకా చదవడానికి వీలుగా, కింద సంతకంతో.

ఎన్‌క్రిప్ట్ చేసిన లేదా సంతకం చేసిన సందేశాన్ని పేస్ట్ చేసి **డిక్రిప్ట్ / ధృవీకరించండి** నొక్కండి: టెక్స్ట్ అక్కడికక్కడే డిక్రిప్ట్ అవుతుంది — అవసరమైనప్పుడు మీ కీ పాస్‌ఫ్రేజ్ అడుగుతుంది — దానిపై ఉన్న ప్రతి సంతకం తనిఖీ చేయబడుతుంది: సరైనది, చెడ్డది (టెక్స్ట్ మార్చబడింది), లేదా మీ కీరింగ్‌లో లేని కీ చేసినది. "అసలు టెక్స్ట్ చూపించు" వెనక్కి తీసుకెళ్తుంది. ⌘/Ctrl+Enter సందేశాన్ని డిక్రిప్ట్ చేస్తుంది, లేదా సాధారణ టెక్స్ట్‌ను ఎన్‌క్రిప్ట్ చేస్తుంది. పేస్ట్ చేసిన కీని ఇంపోర్ట్ చేయమని సూచిస్తుంది.

### ఫైళ్లు

బటన్‌తో ఫైళ్లను జోడించండి లేదా విండోపై వదలండి. ప్రతి ఫైల్‌ను పరిశీలించి అది ఏమిటో గుర్తిస్తారు: సాధారణ ఫైల్, ఎన్‌క్రిప్ట్ చేసినది, సంతకం చేసినది, డిటాచ్డ్ సంతకం, కీలు లేదా ఉపసంహరణ సర్టిఫికెట్.

- **సంతకం / ఎన్‌క్రిప్ట్ చేయండి** — సాధారణ ఫైళ్లకు: మీ కీలలో ఒకదానితో సంతకం చేయండి, మీ కోసం, ఇతరుల కోసం, పాస్‌వర్డ్‌తో, లేదా వీటన్నిటినీ కలిపి ఎన్‌క్రిప్ట్ చేయండి. ఎన్‌క్రిప్ట్ చేసిన ఫైళ్లకు `.gpg` (లేదా టెక్స్ట్‌గా `.asc`) వస్తుంది; సంతకం మాత్రమే చేస్తే ప్రతి ఫైల్ పక్కన డిటాచ్డ్ సంతకం, `.sig` (లేదా `.asc`), తయారవుతుంది.
- **డిక్రిప్ట్ / ధృవీకరించండి** — మిగతా వాటికి. డిటాచ్డ్ సంతకం తాను సంతకం చేసిన ఫైల్‌ను దాని పేరుతో కనుగొంటుంది (`report.pdf.sig` `report.pdf`తో కలుస్తుంది), లేదా అడుగుతుంది. డిక్రిప్ట్ అయిన ఫైళ్లకు ఎన్‌క్రిప్ట్ చేసిన వాటి పేరే `.gpg` లేకుండా వస్తుంది.
- **కీలను ఇంపోర్ట్ చేయండి** — ఇక్కడ వదిలిన కీ ఫైళ్లకు.

ప్రతి ఫలితాన్ని దాని సొంత బటన్‌తో, లేదా అన్నీ ఒకేసారి సేవ్ చేయవచ్చు.

### పాస్ ఫ్రేజ్‌లు

ఒకసారి అన్‌లాక్ చేసిన సీక్రెట్ కీ కొంతసేపు అన్‌లాక్‌గానే ఉంటుంది, gpg-agent దాన్ని ఉంచినట్లే: డిఫాల్ట్‌గా 10 నిమిషాలు, సెట్టింగ్‌లలో "ప్రతిసారీ అడుగు" నుండి నాలుగు గంటల వరకు. డిక్రిప్ట్ చేసిన కీ మాత్రమే పేజీ మెమరీలో ఉంటుంది — పాస్‌ఫ్రేజ్ ఎప్పుడూ కాదు, డిస్క్‌లో ఎప్పుడూ కాదు. మెనూలోని **పాస్‌ఫ్రేజ్‌లు మరచిపో** అన్నిటినీ ఒకేసారి లాక్ చేస్తుంది; పేజీని రీలోడ్ చేసినా అంతే.

### ఫోన్‌లో

పేజీ ఫోన్‌లో పనిచేస్తుంది: ఒకసారికి ఒక స్క్రీన్, వీక్షణలు కింద ట్యాబ్ బార్‌లో, కీ వివరాలు వెనక్కి వెళ్ళే బటన్‌తో సొంత స్క్రీన్‌పై — సిస్టమ్ బ్యాక్ సంజ్ఞ కూడా పనిచేస్తుంది — మెనూలు కింద నుండి పైకి వస్తాయి. iOSలో సేవ్ చేసిన ఫైల్ షేర్ షీట్‌కు వెళ్తుంది, అక్కడ "Save to Files" ఉంటుంది.

## అల్గారిథమ్ ఎంపికలు

| ఎంపిక | GnuPG పేర్లు | గమనికలు |
| --- | --- | --- |
| ECC Curve25519 | ed25519 + cv25519 | డిఫాల్ట్, GnuPG, Kleopatraలో లాగే: చిన్నది, వేగవంతమైనది, అన్ని చోట్ల చదవగలిగేది. |
| ECC NIST P-256, P-384, P-521 | nistp256, nistp384, nistp521 | ECDSA, ECDH. |
| ECC Brainpool P-256, P-384, P-512 | brainpoolP256r1… | ECDSA, ECDH; జర్మన్, యూరోపియన్ వినియోగంలో సాధారణం. |
| RSA 2048, 3072, 4096 | rsa2048… | అత్యంత పాతది, అత్యధికంగా చదవగలిగేది; సృష్టించడానికి కొన్ని సెకన్లు పడుతుంది. |
| Ed25519 + X25519 (OpenPGP v6) | ed25519 + x25519 | RFC 9580 కీలు. **GnuPG, Kleopatra వీటిని ఇంకా చదవలేవు.** |
| Ed448 + X448 (OpenPGP v6) | ed448 + x448 | RFC 9580 కీలు, పైన చెప్పినట్లే. |

ప్రతి కీ అంటే సర్టిఫై చేసి సంతకం చేసే ఒక ప్రాథమిక కీ, ఎన్‌క్రిప్ట్ చేసే ఒక సబ్‌కీ, GnuPG వాటిని తయారుచేసినట్లే. ఇతర అల్గారిథమ్‌ల కీలు — ఉదాహరణకు పాత GnuPG కీరింగ్‌లలోని DSA, ElGamal — చదవబడతాయి, వాడబడతాయి; వాటిలో కొత్తవి మాత్రమే తయారుచేయబడవు. secp256k1ను వదిలేశారు: వేరేలా చెప్పకపోతే openpgp.js దాన్ని తిరస్కరిస్తుంది.

## GnuPG, Kleopatraలతో అనుకూలత

`tests/gnupg.mjs` నిజమైన GnuPGని, తాత్కాలిక హోమ్ డైరెక్టరీలో, యాప్ రాసినదానిపై నడుపుతుంది; `tests/pgp.mjs` GnuPG రాసినదాన్ని చదువుతుంది (`tests/fixtures/gnupg/`, `tools/gnupg-fixtures.sh` ఒకసారి తయారుచేసినవి). రెండు వైపులా తనిఖీ చేయబడింది:

- ఇక్కడ తయారుచేసిన ప్రతి v4 అల్గారిథమ్ కీలను GnuPG వాటి వినియోగంతో సహా ఇంపోర్ట్ చేసి, వాడుతుంది: GnuPG మన సందేశాలను డిక్రిప్ట్ చేస్తుంది, మన సంతకాలను తనిఖీ చేస్తుంది, GnuPG వాటికి ఎన్‌క్రిప్ట్ చేసినదాన్ని మనం డిక్రిప్ట్ చేస్తాము;
- GnuPGకి మన కొత్త గడువు తేదీలు, జోడించిన, ఉపసంహరించిన యూజర్ IDలు, ఇతర కీల సర్టిఫికేషన్లు, ఉపసంహరణ సర్టిఫికెట్లు కనిపిస్తాయి;
- GnuPG కీలు, సందేశాలు (దాని OCB-ఎన్‌క్రిప్టెడ్ వాటితో సహా), క్లియర్-సైన్డ్ టెక్స్ట్‌లు, డిటాచ్డ్ సంతకాలు, పాస్‌వర్డ్‌తో ఎన్‌క్రిప్ట్ చేసిన సందేశాలు, ఉపసంహరణ సర్టిఫికెట్లు ఇక్కడ చదవబడతాయి.

మీ కీలను Kleopatra నుండి తెచ్చుకోవడానికి: మీ కీ జతను ఎంచుకోండి → సీక్రెట్ కీలను ఎక్స్‌పోర్ట్ చేయండి (లేదా "సీక్రెట్ కీల బ్యాకప్"), ఆ ఫైల్‌ను ఇక్కడ ఇంపోర్ట్ చేయండి; ఇతరుల పబ్లిక్ కీలను అదే విధంగా ఎక్స్‌పోర్ట్‌తో. ఇక్కడి నుండి వెనక్కి: పబ్లిక్ కీని ఎక్స్‌పోర్ట్ చేయండి, లేదా సీక్రెట్ కీని బ్యాకప్ చేసి, ఆ ఫైల్‌ను Kleopatraలో ఇంపోర్ట్ చేయండి.

## Chrome పొడిగింపు

అదే యాప్ Chrome సైడ్ ప్యానెల్‌లో, మీరు చదువుతున్న పేజీ పక్కనే. టూల్‌బార్ బటన్ దాన్ని తెరుస్తుంది. ఏ పేజీలోనైనా — వెబ్‌మెయిల్‌లో, ఫోరమ్‌లో, టెక్స్ట్ ఫీల్డ్‌లో — ఎన్‌క్రిప్ట్ చేసిన లేదా సంతకం చేసిన టెక్స్ట్‌ను ఎంచుకుని, కాంటెక్స్ట్ మెనూలో **HTML PGPతో డిక్రిప్ట్ / ధృవీకరించండి** ఎంచుకోండి: అది ప్యానెల్ నోట్‌ప్యాడ్‌లో డిక్రిప్ట్ అయి, తనిఖీ చేయబడి తెరుచుకుంటుంది. **HTML PGPతో ఎన్‌క్రిప్ట్ చేయండి** ఎంచుకున్న టెక్స్ట్‌ను మీకు అందిస్తుంది, గ్రహీతలను మీరు ఎంచుకోవడానికి.

పొడిగింపు వీలైనంత తక్కువ అడుగుతుంది: సైడ్ ప్యానెల్, కాంటెక్స్ట్ మెనూ, దాని సొంత నిల్వ, మీరు క్లిక్ చేసే ట్యాబ్ (activeTab) — ఎంపికను దాని లైన్ బ్రేక్‌లతో చదవడానికి, కాంటెక్స్ట్ మెనూ వాటిని కోల్పోతుంది. ఇతరత్రా దానికి ఏ వెబ్‌సైట్‌కూ యాక్సెస్ లేదు, యాప్ పేజీల లాగే దాని పేజీలకూ నెట్‌వర్క్ యాక్సెస్ లేదు. పేజీని చదవలేని చోట (Chrome సొంత పేజీలు, Web Store, PDF), మెనూ ఇచ్చిన ఎంపిక కాపీని వాడి, దాని ఆర్మర్‌ను తిరిగి దాని లైన్లపై పెడతారు.

పొడిగింపు తన సొంత కీరింగ్‌ను ఉంచుకుంటుంది: బ్రౌజర్‌లు ప్రతి ఆరిజిన్ డేటాను వేరుగా ఉంచుతాయి, కాబట్టి ఒకే ఫైల్, PWA, పొడిగింపు ప్రతిదానికీ సొంతవి ఉంటాయి. వాటి మధ్య కీలను ఎక్స్‌పోర్ట్, ఇంపోర్ట్‌తో లేదా బ్యాకప్‌తో తరలించండి.

దీన్ని `npm run build`తో నిర్మించి `build/extension/`ను `chrome://extensions`లో లోడ్ చేయండి (Developer mode → Load unpacked), లేదా Chrome Web Store కోసం `build/html-pgp-extension-<version>.zip` తీసుకోండి.

## భద్రత

- **పేజీ నుండి ఏదీ బయటకు పోదు.** దాని Content-Security-Policyలో `connect-src 'none'`, `default-src 'none'` ఉన్నాయి: fetch లేదు, ఇతర చోట్ల నుండి చిత్రాలు, ఫాంట్‌లు లేవు, బయటకు పోస్ట్ చేసే ఫారమ్‌లు లేవు. అంతా ఇన్‌లైన్‌లో ఉంది — స్టైల్స్, openpgp.js, ఐకాన్‌లు. ఏ బాహ్య `src` లేదా `href` ఉన్నా బిల్డ్ విఫలమవుతుంది, CI నిర్మించిన ఫైల్‌ను మళ్లీ తనిఖీ చేస్తుంది. PWA కాపీ తన సొంత మానిఫెస్ట్, సర్వీస్ వర్కర్, ఐకాన్‌లను లోడ్ చేయవచ్చు; పొడిగింపు పేజీలకు దాని మానిఫెస్ట్‌లో అదే విధానం ఉంది.
- **సీక్రెట్ కీలు ఎన్‌క్రిప్ట్ చేసి నిల్వ చేయబడతాయి.** కీరింగ్ బ్రౌజర్ IndexedDBలో ఉంటుంది, openpgp.js ఆర్మర్ చేసినట్లుగా ప్రతి కీకి ఒక రికార్డ్: సీక్రెట్ కీ దాని పాస్‌ఫ్రేజ్‌తో ఎన్‌క్రిప్ట్ అయి ఉంటుంది (AES-256, పాస్‌ఫ్రేజ్ నుండి GnuPG లాగే పునరావృత, సాల్ట్ ఉన్న S2Kతో పొందిన కీ), అవసరమైనప్పుడు మాత్రమే మెమరీలో డిక్రిప్ట్ చేయబడుతుంది. పాస్‌ఫ్రేజ్ ఎప్పుడూ నిల్వ చేయబడదు. పాస్‌ఫ్రేజ్ లేని కీని దాని వివరాలలో అలా గుర్తిస్తారు.
- **అన్‌లాక్ చేసిన కీలు మరచిపోబడతాయి** సెట్టింగ్‌లలో నిర్ణయించిన సమయం తర్వాత, "పాస్‌ఫ్రేజ్‌లు మరచిపో" నొక్కినప్పుడు, పేజీ మూసినప్పుడు.
- **పాస్‌ఫ్రేజ్ ఫీల్డ్‌లు ఉద్దేశపూర్వకంగా టెక్స్ట్ ఇన్‌పుట్‌లు**, పారదర్శక టెక్స్ట్‌తో, దానిపై గీసిన చుక్కలతో. macOSలో పాస్‌వర్డ్ ఫీల్డ్ Secure Inputను ఆన్ చేస్తుంది, అది లాటిన్ కీబోర్డ్ లేఅవుట్‌ను బలవంతం చేస్తుంది: సిరిలిక్, గ్రీక్ లేదా అరబిక్‌లో పాస్‌ఫ్రేజ్ టైప్ చేయడం సాధ్యం కాదు. ఈ ఫీల్డ్ బ్రౌజర్‌కు అలాంటి సూచన ఇవ్వదు, అయినా టైప్ చేసినదాన్ని దాచుతుంది, దాన్ని కాపీ చేయనివ్వదు.
- **సంతకాలను మీరు నమ్మే కీల ఆధారంగా అంచనా వేస్తారు.** ఎవరూ సర్టిఫై చేయని కీ నుండి వచ్చిన సరైన సంతకం ఆ విషయాన్ని చెబుతుంది, దాని ఫింగర్‌ప్రింట్‌ను ఎందుకు తనిఖీ చేయాలో కూడా.
- **బ్రౌజర్ నమ్మకమైన పునాది.** ఈ పేజీలో కోడ్ నడపగల లేదా బ్రౌజర్ ప్రొఫైల్‌ను చదవగల ఏదైనా — అన్ని సైట్‌లకు యాక్సెస్ ఉన్న హానికరమైన పొడిగింపు, కంప్యూటర్‌లోని మాల్‌వేర్ — పేజీ చదవగలిగినదాన్ని చదవగలదు. మీ సీక్రెట్ కీల బ్యాకప్‌లను వేరే చోట ఉంచండి: బ్రౌజర్ డేటాను క్లియర్ చేస్తే కీరింగ్ తొలగిపోతుంది.

## ఫీచర్లు

- IndexedDBలో కీరింగ్, ఈ ఆరిజిన్‌లోని యాప్ విండోలు పంచుకుంటాయి; ఒక విండోలోని మార్పు ఇతరులలో కనిపిస్తుంది.
- పన్నెండు రకాల కొత్త కీ జతలు, గడువు తేదీతో, వాటితో పాటు తయారైన ఉపసంహరణ సర్టిఫికెట్‌తో.
- ఆర్మర్డ్, బైనరీ కీల ఇంపోర్ట్, ఒకేసారి అనేకం, ఉన్న వాటితో విలీనం; GnuPG ఉపసంహరణ సర్టిఫికెట్లు నిర్ధారణపై.
- పబ్లిక్ కీల ఎక్స్‌పోర్ట్, సీక్రెట్ కీల బ్యాకప్, ఒకటి లేదా అన్నీ.
- ఇతరుల కీల సర్టిఫికేషన్; మీ సొంత సర్టిఫికేషన్ల నుండి చెల్లుబాటు.
- మీ కీని మార్చడం: గడువు, యూజర్ IDలు, పాస్‌ఫ్రేజ్, ఉపసంహరణ — GnuPG చేసినట్లే సంతకాలను జోడించడం ద్వారా, కాబట్టి కీ అన్ని చోట్ల చదవగలిగేలా ఉంటుంది, ఇతరుల సర్టిఫికేషన్లు దానిపై నిలుస్తాయి.
- నోట్‌ప్యాడ్: ఎన్‌క్రిప్ట్, సంతకం, సంతకం చేసి ఎన్‌క్రిప్ట్, పాస్‌వర్డ్‌తో ఎన్‌క్రిప్ట్, డిక్రిప్ట్, ధృవీకరణ.
- ఫైళ్లు: ఫైళ్లకు అవే, డిటాచ్డ్ సంతకాలు, ఒకేసారి అనేక ఫైళ్లు.
- పాస్‌ఫ్రేజ్‌లు కొంతసేపు గుర్తుంచుకోబడతాయి, మెమరీలో మాత్రమే.
- లైట్, డార్క్ థీమ్, సిస్టమ్‌ను అనుసరిస్తూ లేదా ఎంచుకున్నది.
- 17 భాషలు, అరబిక్, ఉర్దూ కుడి నుండి ఎడమకు.
- ఫోన్ లేఅవుట్; PWA ఫోన్‌లో లేదా కంప్యూటర్‌లో ఇన్‌స్టాల్ అవుతుంది, ఆఫ్‌లైన్‌లో పనిచేస్తుంది.
- Finder లేదా Explorer నుండి ఇన్‌స్టాల్ చేసిన PWAతో తెరిచిన ఫైళ్లు దాని ఫైళ్ల వీక్షణలోకి వస్తాయి.
- ఎంచుకున్న టెక్స్ట్ కోసం కాంటెక్స్ట్ మెనూతో Chrome పొడిగింపు.

## అనువాదాలు

ఇంటర్‌ఫేస్ ఇంగ్లీష్, మరో 16 భాషలు మాట్లాడుతుంది: చైనీస్, హిందీ, స్పానిష్, ఫ్రెంచ్, అరబిక్, బెంగాలీ, పోర్చుగీస్, రష్యన్, ఉర్దూ, ఇండోనేషియన్, జర్మన్, జపనీస్, మరాఠీ, తెలుగు, టర్కిష్, ఉక్రెయినియన్. సెట్టింగ్‌లలో ఒకటి ఎంచుకోకపోతే ఇది బ్రౌజర్ భాషను అనుసరిస్తుంది. అరబిక్, ఉర్దూ కుడి నుండి ఎడమకు అమర్చబడతాయి.

ఇంగ్లీష్ టెక్స్ట్ కోడ్‌లో ఉంటుంది: `t('context', 'English text')`, లేదా సంఖ్య ఉన్న టెక్స్ట్ కోసం `tn('context', '{count} key', '{count} keys', n)`, సాధారణ స్ట్రింగ్ లిటరల్స్‌తో — `tools/i18n.mjs` వాటిని రెగ్యులర్ ఎక్స్‌ప్రెషన్‌తో కనుగొంటుంది. టెంప్లేట్‌లో `data-i18n` ఎలిమెంట్ టెక్స్ట్‌ను అనువదిస్తుంది, `data-i18n-attr` దాని title, placeholder, aria-labelను. ప్రతి భాష ఒక డిక్షనరీ, `src/locales/<code>.json`: `{ "context": { "English text": "translation" } }`, బహువచన రూపాలు `Intl.PluralRules`తో. డిక్షనరీలో లేని స్ట్రింగ్ ఇంగ్లీష్‌లో చూపబడుతుంది.

`npm run i18n` ప్రతి భాషకు, డిక్షనరీలో లేని స్ట్రింగ్‌లను, అందులో ఉండి ఇంటర్‌ఫేస్ ఇకపై వాడని వాటిని ముద్రిస్తుంది; `npm test` డిక్షనరీలను తనిఖీ చేస్తుంది: పాత కీలు లేవు, ఒకే ప్లేస్‌హోల్డర్‌లు, ప్రతి బహువచన రూపం, ప్రతి సందర్భం ఒక్కసారే. Chrome పొడిగింపు గురించి స్వయంగా చూపేది — దాని పేరు, వివరణ, బటన్ శీర్షిక — అవే డిక్షనరీల నుండి వస్తుంది, సందర్భం `manifest`.

## బిల్డ్

```sh
npm install
npm run build          # build/html-pgp.html, build/pages/, build/extension/ మరియు దాని zip
npm run watch          # ప్రతి మార్పుపై మళ్లీ నిర్మిస్తుంది
./build.sh             # అదే, మొదటిసారి డిపెండెన్సీలను ఇన్‌స్టాల్ చేస్తూ
```

`build.mjs` `src/app/main.ts`ను esbuildతో ఒక స్క్రిప్ట్‌గా బండిల్ చేసి, దాన్ని, స్టైల్స్‌ను, ఐకాన్‌ను `src/app/template.html`లో ఇన్‌లైన్ చేస్తుంది. openpgp.js ఒక్కటే రన్‌టైమ్ డిపెండెన్సీ.

```sh
npm run check          # కింది అన్నీ, వరుసగా
npm run typecheck      # tsc --noEmit
npm test               # Nodeలో యూనిట్ పరీక్షలు; tests/gnupg.mjsకు gpg కావాలి, లేకపోతే ఆ మాట చెబుతుంది
npm run test:browser   # పేజీ, PWA, పొడిగింపు హెడ్‌లెస్ Chromeలో
npm run shots -- DIR   # ప్రతి ప్రధాన స్క్రీన్ స్క్రీన్‌షాట్‌లు DIRలోకి
npm run icons          # PNG ఐకాన్‌లు, assets/*.svg నుండి గీసినవి
```

బ్రౌజర్ పరీక్షలు స్థానిక Chromeను DevTools ప్రోటోకాల్ ద్వారా నడుపుతాయి, Node తప్ప ఇతర డిపెండెన్సీలు లేకుండా; `CHROME=/path/to/chrome` ఒకదాన్ని ఎంచుకుంటుంది.

## వెర్షన్లు, రిలీజ్‌లు

వెర్షన్ `package.json`లో మాత్రమే ఉంటుంది. `v<version>` అని ట్యాగ్ చేసిన కమిట్ యొక్క బిల్డ్ దాన్ని ఉన్నదున్నట్లు చూపుతుంది; ఇతర ఏ బిల్డ్ అయినా కమిట్‌ను జోడిస్తుంది — `0.1.0+1a2b3c4` — కాబట్టి `main` నుండి నిర్మించిన పేజీని రిలీజ్ అనుకోరు. రిలీజ్ చేయడానికి: `npm version minor && git push --follow-tags`. రిలీజ్ వర్క్‌ఫ్లో ట్యాగ్ `package.json`తో సరిపోతుందో లేదో తనిఖీ చేస్తుంది, పరీక్షలు నడుపుతుంది, `html-pgp-<tag>.html`, `html-pgp-extension-<tag>.zip`, `SHA256SUMS.txt`లను జతచేస్తుంది.

## GitHub Pages

`build/pages/` అదే పేజీ ఇన్‌స్టాల్ చేయదగిన PWAగా: ఒక మానిఫెస్ట్, ఐకాన్‌లు, ఒకసారి తెరిచాక ఆఫ్‌లైన్‌లో పనిచేసేలా ఉంచే సర్వీస్ వర్కర్. `.github/workflows/pages.yml` ప్రతి `main` పుష్‌పై దాన్ని నిర్మించి, పరీక్షించి, GitHub Pagesకు డిప్లాయ్ చేస్తుంది (Settings → Pages → Source: GitHub Actions); అప్పుడు అది `https://<owner>.github.io/html-pgp/` వద్ద ఉంటుంది.

పేజీ ఇప్పటికీ దేనినీ చేరదు: దాని విధానం తన సొంత మానిఫెస్ట్, వర్కర్, ఐకాన్‌లను మాత్రమే లోపలికి రానిస్తుంది. కొత్త డిప్లాయ్ నడుస్తున్న వెర్షన్ పక్కన ఇన్‌స్టాల్ అయి వేచి ఉంటుంది; సెట్టింగ్‌లు "వెర్షన్ X సిద్ధంగా ఉంది." అని, "అప్‌డేట్ చేయండి" బటన్‌ను చూపుతాయి, సెట్టింగ్‌లపై ఒక చుక్క గుర్తు ఉంటుంది. ఇన్‌స్టాల్ చేసిన యాప్ సిస్టమ్ నుండి `.gpg`, `.pgp`, `.sig`, `.asc` ఫైళ్లను కూడా (Open With) తన ఫైళ్ల వీక్షణలోకి తెరుస్తుంది.

## పరిమితులు

- కీ సర్వర్లు, WKD లేవు: పేజీకి రూపకల్పన ప్రకారమే నెట్‌వర్క్ యాక్సెస్ లేదు. కీలను ఫైళ్లుగా లేదా టెక్స్ట్‌గా మార్చుకోండి.
- స్మార్ట్‌కార్డ్‌లు, హార్డ్‌వేర్ టోకెన్‌లు లేవు. సీక్రెట్ ప్రాథమిక కీ వేరే చోట ఉంచిన కీలు (GnuPG స్టబ్‌లు) చదవబడతాయి, వాటి సబ్‌కీలు పనిచేస్తాయి; అలాంటి కీని ఇక్కడ మార్చలేరు.
- S/MIME, X.509 సర్టిఫికెట్లు లేవు — OpenPGP మాత్రమే.
- నమ్మకం ప్రత్యక్షమైనది: మీ సొంత కీల సర్టిఫికేషన్లు. GnuPG owner trust — ఇతరుల సర్టిఫికేషన్లను నమ్మడం — మోడల్ చేయలేదు.
- ఫైళ్లను పూర్తిగా మెమరీలోకి చదువుతారు: పత్రాలు, ఫోటోలకు సరే, గిగాబైట్లకు కాదు.
- ఒకే ఫైల్, PWA, పొడిగింపు ప్రతిదీ తన సొంత కీరింగ్‌ను ఉంచుకుంటాయి ("[Chrome పొడిగింపు](#chrome-పొడిగింపు)" చూడండి).
- OpenPGP v6 కీలను GnuPG, Kleopatra ఇంకా చదవలేవు.
